# image-replacer

웹페이지의 이미지를 원하는 이미지로 교체하는 Chrome 확장 기능입니다.

## 주요 기능

- `<img>` 이미지 교체
- `<picture>` 내부 `source[srcset]` 정리
- inline `background-image` 교체
- favicon 교체
- 선택적 `::before`, `::after` 배경 이미지 교체
- 선택적 SVG 교체
- 사이트별 제외 도메인 설정
- popup에서 확장 사용 여부와 교체 옵션 관리

## 설치 방법

1. 이 저장소를 다운로드하거나 clone합니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. 우측 상단의 개발자 모드를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
5. 이 저장소 폴더를 선택합니다.

## 사용 방법

확장 아이콘을 누르면 설정 popup이 열립니다.

- `확장 기능 사용`으로 전체 이미지 교체를 켜고 끌 수 있습니다.
- `교체 이미지 URL`에 원하는 이미지 주소를 입력할 수 있습니다.
- URL을 비워두면 확장에 포함된 기본 이미지를 사용합니다.
- favicon, inline background, pseudo-element background, SVG 교체 여부를 각각 선택할 수 있습니다.
- 제외 도메인은 한 줄에 하나씩 입력합니다. 예를 들어 `youtube.com`을 입력하면 `www.youtube.com`도 제외됩니다.

## 성능 개선 내용

이 확장은 동적으로 추가되는 이미지를 처리하기 위해 `MutationObserver`를 사용합니다. 기존처럼 DOM 전체를 반복적으로 스캔하지 않고, 변경된 노드만 큐에 넣어 처리합니다. 또한 `requestIdleCallback`을 우선 사용하여 브라우저가 비교적 여유로운 시점에 교체 작업을 수행합니다.

## 한계

1. 일부 사이트는 이미지 로딩, lazy loading, Shadow DOM, canvas 렌더링, 자체 보안 정책 때문에 완전히 교체되지 않을 수 있습니다.
2. `::before`, `::after` 배경 이미지 교체는 전역 CSS를 주입하므로 기본값으로 꺼져 있습니다. 필요한 경우에만 켜는 것이 좋습니다.
3. SVG 교체는 아이콘 기반 UI를 망가뜨릴 수 있어 기본값으로 꺼져 있습니다.
4. 이미 교체된 이미지를 원래 이미지로 되돌리는 기능은 아직 제공하지 않습니다. 설정을 끈 뒤 새로고침하면 원래 페이지가 다시 표시됩니다.

## 개인정보

이 확장은 사용자의 페이지 데이터를 외부 서버로 전송하지 않습니다. 설정은 Chrome의 `storage.sync`에 저장됩니다.
